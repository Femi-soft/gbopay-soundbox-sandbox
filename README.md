# GboPay Soundbox Sandbox

Public Android test builds for GboPay Soundbox.

## Download

[Download the latest Android APK](https://github.com/Femi-soft/gbopay-soundbox-sandbox/releases/download/v0.2.0/GboPay-Soundbox-Sandbox-v0.2.0.apk)

Open the link on an Android phone, allow installation from your browser when
prompted, then install the downloaded APK. Android 8.0 or newer is required.

> **Testing only:** This sandbox demonstrates the merchant experience. Do not
> treat its demo payments as real or verified money.
